## Aftergodsの戦闘における基本システム

本作の戦闘の核となるのは、厳密に調整された「リソース管理」「攻撃の緩急（ペーシング）」「神の勢い（Divine Momentum）」という3要素の調和です。一般的なハック＆スラッシュ作品とは異なり、本作の立ち回りでは、すべてのキー入力やボタン操作に明確な意図が求められます。

### ニュートラル（立ち回り）時のリズム

すべての戦闘は、上級プレイヤーが「ニュートラルフェーズ（差し合いの状況）」と呼ぶ状態から始まります。ニュートラル時の主な目的は、間合いの管理と敵の行動パターンの把握です。敵は連続攻撃を繰り出す前に、予備動作となる特有のモーションを見せます。敵の硬直（リカバリーフレーム）を把握しないまま攻撃間合いに踏み込めば、手痛いカウンターを被ることになるでしょう。

優勢を維持するには、スタミナゲージを絶対にゼロにしないことが肝心です。スタミナを完全に使い果たすとキャラクターが疲労（息切れ）状態に陥り、数秒間の決定的な隙が生じて回避や攻撃の受け流しが一切不可能になります。

### リソースプールと神の恩寵（Divine Favor）

標準的なHP（体力）やスタミナゲージに加え、プレイヤーは「神の恩寵（Divine Favor）」も管理しなければなりません。神の恩寵は、連続攻撃のヒット、見事な回避の成功、体勢崩しの発生などによって蓄積されます。この恩寵を消費することで、戦況を一変させる強力なレリック効果や壊滅的な武器スキル（戦技）を発動し、苦境を打破することが可能です。

| 戦闘リソース | 主な役割 | 枯渇時のペナルティ | 回復方法 |
| :--- | :--- | :--- | :--- |
| **体力／HP (Vitality)** | キャラクターの生存許容量 | 死亡 / 祭壇でのリスポーン | エリクサー、ライフスティール効果、神の恩恵（Boon） |
| **スタミナ (Vigor)** | 攻撃、回避、ダッシュの原動力 | 疲労によるよろけ、回避不可 | 待機時または歩行時の自然回復 |
| **神の恩寵 (Divine Favor)** | バーストスキルや神聖能力の発動源 | 上位アビリティの発動不可 | 攻撃ヒット、パリィ、ジャスト回避 |
| **強靭度／体勢 (Poise/Stance)** | モーション中の被弾よろけを防止 | 転倒、体勢崩れ、致命的な隙の発生 | 離脱後または体勢回復によるリセット |

これらのリソースを同時に管理し切ることが、本作におけるスキルの登竜門となります。複数の敵を相手にする混戦では、神聖ゲージとスタミナバーの双方に常に気を配ることで、脱出手段を失ったまま袋小路に追い込まれる事態を防げます。

## 防御メカニクス：パリィ、回避、体勢崩し

**Aftergodsの戦闘**を真に極めるには、猛烈な攻撃性と同じくらい強固な防御への理解が不可欠です。立ち止まって迎え撃つべきか、位置を取り直すべきかの判断が、あらゆる難易度における勝敗を分けます。

### 完璧な受け流し（パーフェクトパリィ）の極意

敵の攻撃を受け流すことで、その運動エネルギーを相手自身へと跳ね返します。敵の武器が接触する瞬間に合わせてパリィを成功させれば、自身の立ち位置を維持したまま、敵の体勢値（ポイズ）に甚大なダメージを与えることができます。

プレイヤーの検証によれば、多段コンボをすべて受け流そうとするとタイミングがシビアになりリスクが高まるため、初撃をパリィして続く追撃は回避で躱すのが安全策とされています。また、上位の敵はパリィのタイミングを狂わせるためにディレイ（遅らせ）攻撃を頻繁に使ってくるため、武器の輝きではなく腕の振りかぶりモーションを注視することが成功への近道です。

### 回避と無敵時間（無敵フレーム）

ローリングやステップ移動には貴重な無敵フレーム（i-frame）が付与されています。しかし、1回回避するごとにスタミナゲージを一定量消費します。連続して回避を繰り返すとあっという間にスタミナ切れを起こし、広範囲を薙ぎ払う追撃に対して完全に無防備になってしまいます。

回避する方向の判断は極めて重要です。敵の攻撃の発生側へ向かってすれ違うようにローリングすると、敵の死角に回り込みやすく、即座にバックスタブや強力な反撃を叩き込むチャンスが生まれます。逆に、真後ろへのローリングは長柄武器の突き刺し攻撃や衝撃波の攻撃判定に巻き込まれやすいため注意が必要です。

| 防御アクション | 発生ウィンドウ | スタミナ消費 | 主な戦術的利点 | 内包するリスク |
| :--- | :--- | :--- | :--- | :--- |
| **パーフェクトパリィ** | 発生4〜6フレーム | 低 | 敵の体勢に特大ダメージ、即座にクリティカル反撃 | タイミング失敗時に全ダメージを直接被弾 |
| **通常ガード** | ガード姿勢の維持 | 中（被弾時に消費） | 確実な物理ダメージ100%カット（盾装備時） | ガード崩しキックや強打攻撃に脆弱 |
| **方向指定回避** | 入力直後から即座 | 中 | 完全な無敵フレーム、側面・背面への位置取り | 終わり際の硬直を捉えられると被弾 |
| **アーマー受け（Stance Absorb）** | 武器固有のスーパーアーマー | 高 | 攻撃モーションの中断を防ぐ | 削りダメージを一部受ける |

### 体勢崩しと致命の一撃（クリティカルストライク）

すべての敵には目に見える、あるいは不可視の体勢ゲージが存在し、重攻撃、パリィ、打撃属性の攻撃を浴びせ続けることで削られていきます。ゲージを完全に削り切ると、敵は長時間無防備になる「体勢崩れ状態」に陥ります。バランスを崩した敵に接近して攻撃を入力することで「致命の一撃（処刑攻撃）」が発動し、絶大な確定ダメージを与えつつ、モーション中は周囲の攻撃から完全無敵となります。

## 武器種とステータス補正

選択した武器種によって、戦いのテンポと手応えは劇的に変化します。荒廃した世界での過酷な試練を乗り越えるには、自身のプレイスタイルに合った獲物を見つけ出すことが不可欠です。

```
[俊敏な決闘者：短剣／刺突剣] <---> [万能の遊撃手：直剣／長槍] <---> [重量級の一撃：大剣／大槌]
```

ビルドの最適化にあたっては、[Steamコミュニティハブ](https://store.steampowered.com)などの有志リポジトリや最新のパッチノートを確認することで、変化するフレームデータやステータス補正の基準値に関する貴重な情報を得られます。

### 軽量刃と刺突武器

双短剣、曲剣、レイピアなどの軽量武器は、出血、腐敗、神聖炎上といった状態異常の蓄積に極めて長けています。一撃あたりの基礎ダメージは控えめですが、攻撃後の硬直が非常に短いため、危険地帯へヒット＆アウェイを繰り返す反射神経重視のプレイヤーにとって非常に扱いやすい選択肢となります。

### 重打撃武器と特大剣

重量級の武装は、圧倒的な体勢削り能力とスーパーアーマー（強靭度付与フレーム）を誇ります。特大剣や巨大な戦槌を振り抜く際、敵の軽攻撃を受けてもモーションが中断されることはありません。ただし、振りの後のリカバリー時間が長いため、空振りを起こすと致命的な隙を晒すことになります。

### 長柄武器と神聖触媒

長柄武器（槍・ハルバード）は無類のリーチを誇り、獰猛な獣を安全な間合いに抑え込みながら、わずかな隙を突く攻撃が可能です。一方、神聖触媒は中〜遠距離の呪文行使を可能にし、神の恩寵を消費して天界の業火を降らせたり、術者の周囲に守りの結界を展開したりできます。

## 戦闘アーキタイプとビルドシナジー

### アイアン・ヴァンガード（鉄壁の前衛）

厚手の重装甲、大盾、そして粉砕系の重武器を軸とするビルドです。最大の強靭度と物理ダメージ軽減を誇り、巨大な敵と正面から殴り合っても怯まず、豪快な振り下ろしの一撃で敵のガードや体勢を粉砕します。

* **主な強み:** 豊富なHPプール、高い強靭性、安定した集団制御力。
* **致命的な弱点:** 回避距離の短さ、遅いスタミナ回復速度、属性攻撃に対する耐性の低さ。

### セレスティアル・ウィーバー（星紡ぎの術士）

* **主な強み:** 安全な交戦距離、強力な範囲攻撃（AoE）、高い属性バーストダメージ。
* **致命的な弱点:** 紙一重の軽装防御力、神の恩寵の生成効率への極端な依存。

## ボス攻略：Aftergodsの実践的ハイレベル戦術

強大なボス戦は、位置取り、忍耐力、反射速度といったこれまでに培った技術のすべてが試される場です。本作のボスは複数のフェーズ（段階）を持ち、体力が減るにつれて行動パターン、攻撃性、フィールド上のギミックが変化します。

### フェーズ移行時の対応手順

ボスの体力が特定の閾値（主に約70%と30%）を下回ると、無敵状態を伴うフェーズ移行モーションに入り、エリア全体への壊滅的な衝撃波を放つことが多々あります。移行モーションを確認したら、即座に間合いを取って余計な被弾を防ぐことが鉄則です。

```
第1フェーズ交戦（攻撃を誘発し予備動作を覚える） 
      │
      ▼
フェーズ移行を察知（即座に離脱して距離を取る）
      │
      ▼
第2フェーズへの適応（広範囲攻撃を躱し新たな硬直の隙を突く）
```

第2フェーズでは、ボスの通常攻撃に神聖属性や壊死属性が付与され、通常の物理ガードを貫通してくるケースが増加します。盾に頼って防御を固めるよりも、正確なローリング回避やパーフェクトパリィを軸にする方が遥かに安全です。

### 硬直の隙（リカバリーウィンドウ）を見極める

ボスの大技コンボの終了後には、必ず体勢を立て直すための硬直時間が存在します。プレイヤーの検証でも明らかになっている通り、この隙に欲張って4〜5発の攻撃を叩き込もうとすると、ボスの起き上がり反撃をほぼ確実に喰らってしまいます。重攻撃なら2発、出の速い軽攻撃でも3発程度に留め、すぐに防御態勢へ戻るのが鉄則です。

| ボスの進行フェーズ | 典型的なボスの行動 | 最適な戦術対応 | よくあるプレイヤーのミス |
| :--- | :--- | :--- | :--- |
| **開幕フェーズ (100–70%)** | 規則正しいコンボ、分かりやすい予備動作 | 初撃を誘い、パリィのタイミングを掴む | 序盤でスタミナを使い果たす |
| **激昂への移行 (~70%)** | 咆哮、衝撃波、属性付与 | 後方へダッシュ離脱、新モーションを観察 | 無敵フレーム中に攻撃を仕掛ける |
| **狂乱フェーズ (70–30%)** | 長い連撃、急速接近、広範囲AoE | 横方向へ回避し、コンボの最終段のみを反撃 | 属性の削りダメージを無理にガードする |
| **決死フェーズ (&lt;30%)** | 苛烈な猛攻、硬直時間の短縮 | 温存した恩寵レリックを解放し一気に削り切る | 直線的な後方ローリングでパニック回避 |

このチェックリストを忠実に実行することで、圧倒的な神話の怪物との死闘も、安定して再現可能な勝利へと変えることができます。

## 初心者が押さえるべき5つの実践的戦闘のコツ

ゲームのシステムをより早くマスターするために、日々のプレイで以下の行動を習慣化しましょう：

1. **スタミナの最後の1ゲージを決して使い切らない:** 緊急時のローリングを行えるよう、スタミナゲージの最低でも10〜15%は常に残しておきましょう。
2. **刃先ではなく「肩」を見る:** 敵の攻撃の予備動作は腰や肩から始まります。武器の軌跡ではなく体の動きを注視することで、受け流しのタイミングが劇的に安定します。
3. **装備重量は「軽装」または「中装」を維持する:** 重量過多の上限を下回る状態を保つことで、ローリング速度、スタミナ回復速度、回避距離を高い水準に維持できます。
4. **投擲アイテムで敵の群れを分断する:** 孤立した敵を1体ずつ釣り出すことで、狭い通路などで囲まれて圧殺されるリスクを回避できます。
5. **基礎ステータスより武器強化を優先する:** 序盤においては、ステータスを振るよりも武器レベルを直接強化した方が、遥かに高いダメージ上昇効率を得られます。

## 『Aftergods』戦闘に関するよくある質問（FAQ）

### 『Aftergods』の戦闘でパリィのタイミングを上達させるには？
受け流しの精度を上げるには、敵ごとの攻撃発生フレームを体に覚えさせることが不可欠です。リスポーン地点の近くにいる単体の雑魚敵を相手に練習しましょう。敵が武器を振り上げた瞬間ではなく、腕がプレイヤーに向かって加速して振り下ろされる瞬間にパリィを入力するのがコツです。

### 『Aftergods』の戦闘では防具の防御力と機動力のどちらが重要？
どちらのビルドも通用しますが、実力の上限を最大限に引き出せるのは一般的に機動力です。装備重量を「中装」または「軽装」に抑えることで、スタミナ回復が早まり回避の無敵時間が伸びるため、上級プレイヤーは重装甲で耐えるのではなく、ダメージそのものを完全に無力化できます。

### 強靭度（Poise）は戦闘にどのように影響しますか？
強靭度は、攻撃中に怯んだり動作を中断されたりすることに対する耐性を決定します。強靭度が高ければ、軽量武器を持つ敵から攻撃を受けてもこちらの攻撃モーションがキャンセルされずに相打ちに持ち込めるため、特大剣や大槌を扱うビルドには必須のステータスとなります。

### 敵にいつもガードを崩されてしまう場合の対処法は？
盾ガードが崩され続ける場合、自身のスタミナ許容量を超える攻撃を受けているか、ガード不能の強打攻撃を受けている可能性が高いです。大振りの叩きつけ攻撃には横方向へのローリング回避に切り替え、受け身のガードではなくパリィを活用してスタミナの消耗を抑えましょう。
